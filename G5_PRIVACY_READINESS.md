# G5 privacy readiness notice

**This document is preliminary and not a complete production privacy policy. No signed G5 release is available.**

Orca G5 is an independent experimental fork of [stablyai/orca](https://github.com/stablyai/orca). The code includes network-capable functionality such as model-provider connectors, remote terminals/hosts, agents and updates. Requests, commands, prompts, user credentials and other data may be processed by the providers or remote machines configured or invoked by the user. The exact types, destinations and defaults require an independent audit before G5 can be offered to end users.

G5 has not yet established a definitive inventory of all automatic network requests, telemetry, crash reporting, credential storage or installation-time changes. Do not assume the fork is offline-only or transfers no personal information. Check the [upstream documentation](https://github.com/stablyai/orca) and the terms and privacy policies of configured external providers.

The maintainer must document data flows, optional disable controls, installation disclosures and effective uninstallation before making a G5 production release. A production installer must disclose any collection sent to systems not explicitly specified by the user and provide disable options in accordance with the applicable signing policy.

For now this source branch is public for review, **not a validated or signed end-user distribution**.
