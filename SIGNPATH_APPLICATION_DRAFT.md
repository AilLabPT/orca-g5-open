## Project summary

Orca G5 is an independently maintained modification of the open-source Orca agent IDE, based on the signed upstream Orca v1.4.246 release. It adds experimental G5 server deployment and rollback checks and Windows process-identity validation. The source is available for public review and contains no G5 production-signed installer. A separate isolated Windows QA build was made and tested, but that artifact must not be mistaken for a public signed release.

The proposed purpose of free SignPath Foundation signing is to distribute reviewed, reproducibly built G5-owned Windows installers with a publisher signature, after SignPath's approval.

## Current gaps (must not be represented as complete)

- The project is a newly published fork; active public maintenance history and prior publicly documented release evidence are not yet established.
- User privacy disclosures for all upstream and G5 network-capable components are pending independent review.
- SignPath authors, reviewers and signing approvers, plus MFA, must be verified.
- The SignPath Foundation's policy restricts hacking/security-bypass tools and requires a demonstrated public open-source reputation; eligibility remains at the Foundation's discretion.
- No authorized SignPath organization, API token, signing-policy slug or approval exists for G5.
- No G5 signed binary or public production download is available.

## Submission route

The repository owner should complete the official application at https://signpath.org/apply.html, using the public repository and actual project details. Application and signing credentials require the owner's authenticated action. SignPath approval must be recorded before any signing workflow is enabled.
